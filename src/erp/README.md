## مخطط قاعدة البيانات والعلاقات

### موديول المحاسبة (Accounting)
```
chart_of_accounts (code PK)
    ↑ referenced by
journal_lines (account_code FK)
    ↓ belongs to
journal_entries (id PK)
    ← referenced by all invoice tables via journal_entry_id
```

### موديول المبيعات (Sales)
```
customers ←──── quotes ────── quote_lines ──→ products
                  ↓ convert_quote_to_order()
         ←──── sales_orders ── sales_order_lines ──→ products
                  ↓ invoice_sales_order() → record_sale()
         ←──── sales_invoices ──────────────────────→ journal_entries
                                                     ↓ (stock_moves OUT)
                                                     products (qty ↓)
```

### موديول المشتريات (Purchasing)
```
purchase_requests ── purchase_request_lines ──→ products
    ↓ approve_purchase_request()
    ↓ convert_pr_to_po()
vendors ←──── purchase_orders ── purchase_order_lines ──→ products
                  ↓ receive_purchase_order() → record_purchase()
         ←──── purchase_invoices ───────────────────────→ journal_entries
                                                          ↓ (stock_moves IN)
                                                          products (qty ↑, avg_cost updated)
```

### موديول المخزون (Inventory)
```
warehouses
    ↑ referenced by
products (warehouse_id FK, category_id FK)
    ↑ referenced by
stock_moves (product_id FK) ← generated by record_sale / record_purchase
product_categories (self-referential tree via parent_id)
```

## دورة حياة المستند (Document Lifecycle)

### مبيعات
```
QUOTE [draft] → [sent] → [accepted]
    → convert_quote_to_order()
SALES ORDER [confirmed] → [in_progress] → [shipped] → [delivered]
    → invoice_sales_order() → record_sale() [ATOMIC]
        ✓ يخصم المخزون (stock_moves OUT)
        ✓ يحسب COGS بمتوسط التكلفة المرجّح
        ✓ يرحّل قيداً محاسبياً متوازناً:
            DR Receivable/Cash/Bank  = إجمالي مع ضريبة
            CR Sales Revenue         = صافي المبيعات
            CR VAT Output            = ضريبة المخرجات
            DR COGS                  = تكلفة البضاعة
            CR Inventory             = تخفيض المخزون
SALES INVOICE [created + posted in one atomic transaction]
```

### مشتريات
```
PURCHASE REQUEST [draft] → [pending_approval] → [approved]
    → convert_pr_to_po()
PURCHASE ORDER [draft] → [sent] → [confirmed]
    → receive_purchase_order() → record_purchase() [ATOMIC]
        ✓ يزيد المخزون (stock_moves IN)
        ✓ يحدّث متوسط التكلفة المرجّح
        ✓ يرحّل قيداً محاسبياً متوازناً:
            DR Inventory             = قيمة البضاعة
            DR VAT Input             = ضريبة المدخلات
            CR Payable/Cash/Bank     = إجمالي مع ضريبة
PURCHASE INVOICE [created + posted in one atomic transaction]
```

## API Reference

### Authentication
كل الطلبات تحتاج:
```
Authorization: Bearer {supabase_jwt}
```

### Response Format
**نجاح:**
```json
{ "data": {...}, "message": "اختياري" }
```
**خطأ:**
```json
{ "error": { "message": "وصف الخطأ", "code": 400 } }
```

## خطوات تشغيل Migration

1. افتح **Supabase → SQL Editor → New Query**
2. الصق محتوى `supabase/migrations/009_erp_documents.sql`
3. اضغط **Run**
4. تحقق: `select count(*) from quotes;` — يجب أن يعود `0`
